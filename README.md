# 🌐 Personal Portfolio & Resume

My personal portfolio website and ATS-compliant resume, hosted online via GitHub Pages.

## 🔗 Live Links
* **Live Portfolio Website**: [astitwa2006.github.io](https://astitwa2006.github.io)
* **Interactive Resume**: [astitwa2006.github.io/resume.html](https://astitwa2006.github.io/resume.html)

---

## 🛠️ Features

### Portfolio Website (`index.html`)
* **Modern Aesthetic**: Dark/brutalist design with high contrast acid lime elements.
* **Fluid Experience**: Custom smooth cursor tracking and scroll-path tracer.
* **Responsive**: Mobile-first design that scales perfectly across all screen sizes.
* **Interactive Sections**: Infinite marquee skill tickers, project hover effects, and interactive contact links.

### ATS-Friendly Resume (`resume.html`)
* **Standard Typography**: Clean academic serif typesetting (`Times New Roman` / `Georgia`).
* **High Contrast**: Perfect readability for Automated Tracking Systems (ATS) and human recruiters.
* **Print Optimized**: Custom print media CSS rules so it saves cleanly to a single-page A4 PDF from any browser.
* **Zero Fake Details**: Highlights real full-stack work (`santhalstrikers.in`) and core portfolio projects.
